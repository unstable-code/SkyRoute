# TaxiTimer

World of Warcraft 불타는 성전 클래식(Anniversary) 용 비행 타이머 애드온.

비행 경로마다 실제로 걸린 시간을 기록해 두었다가, 다음에 같은 경로를 탈 때 남은 시간과 지나고 있는 경유지를 보여 줍니다.

## 기능

- **비행 지도 툴팁** — 목적지에 마우스를 올리면 기록된 비행 시간을 표시
- **타이머 창** — 비행 중 남은 시간을 카운트다운. 처음 가는 경로는 경과 시간을 세고, 기록보다 늦어지면 `+` 로 초과 시간 표시
- **경유지 진행도** — 타이머 창에 마우스를 올리면 출발·도착·경과 시간과 함께 지금 지나는 경유지를 표시. 경과 시간 비율과 지역 변경을 함께 사용해 추정
- **자동 기록** — 착륙하면 소요 시간을 저장. 소환·전장 입장·조기 착륙으로 중단된 비행은 기록하지 않음
- **파티 알림** (선택) — 이륙할 때 파티 채널에 목적지를 알림

기본 데이터는 포함하지 않습니다. 모든 기록은 직접 비행하며 쌓이고, 캐릭터 간에 공유됩니다.

## 명령어

`/taxitimer` 또는 `/taxi`

| 명령 | 설명 |
|---|---|
| `show` | 타이머 창을 표시 (드래그로 위치 조정) |
| `hide` | 타이머 창을 숨김 |
| `reset` | 타이머 창 위치 초기화 |
| `chat` | 채팅창 안내 출력 켜기/끄기 |
| `party` | 파티 채널 목적지 알림 켜기/끄기 |
| `debug` | 디버그 출력 켜기/끄기 |
| `help` | 도움말 |
